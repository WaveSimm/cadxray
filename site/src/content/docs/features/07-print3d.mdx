슬라이서에 넣기 전에 모델이 출력 가능한지 검토하는 일입니다. 얇은 벽이 노즐보다 가는지, 서포트 없이 뽑을 수 있는지, 베드에 들어가는지를 AI 가 검사하고, 고칠 수 있는 것은 PartDesign 피처로 고쳐 줍니다(되돌리기 = 피처 삭제). 슬라이싱 자체는 하지 않습니다.

## 이런 걸 시킬 수 있습니다

| 이렇게 말하면 | 무엇이 나오는가 |
|---|---|
| "PETG, 0.6 노즐로 서포트 없이 뽑게 봐줘" | 점수와 문제 목록(얇은 벽·오버행·브릿지·작은 구멍·수평 구멍·베드·첫 층 접지), 각각 심각도·위치·고칠 방법 |
| "어느 방향으로 놓는 게 좋아?" | 6방향 + 현재 방향을 서포트 면적·접지·높이로 채점한 순위. 고르면 회전 적용 |
| "코끼리발이랑 구멍 보정 적용해" | 바닥 바깥 모서리 챔퍼, 수직 구멍을 보정값만큼 키우는 Pocket |
| "수평 구멍 눈물방울로" | 수평 구멍 위에 45° 눈물방울 |
| "얇은 벽 두껍게" | 얇은 평면을 바깥쪽으로 최소 두께까지 Pad (외형 치수가 변함) |
| "오버행 아래 쐐기 넣어" | 재료에 붙은 평면 오버행 아래를 한계각 경사로 메움 |
| "베드보다 크니까 잘라줘" | 축 방향으로 조각 분할, 원본 숨김(접합 핀은 수동) |
| "이거 뽑으면 몇 g, 몇 시간, 얼마?" | 재료 부피·무게·필라멘트 길이·시간·비용 |
| "문제 있는 면 색으로 칠해줘" | 얇은 벽 빨강, 서포트 주황, 브릿지 노랑, 접지 초록 |

## 대표 프롬프트

```text title="이렇게 말한다"
Body 'SpoolGuide' 를 PLA, 0.4 노즐, 0.2 레이어, 베드 220×220×250 으로 검토해줘.
문제를 번호 목록으로 보여주고, 고칠 수 있는 건 후보만 보여줘. 자동으로 고치지 마.
```

:::note[AI 는 이렇게 답합니다]
프로파일: PLA · 노즐 0.4 · 레이어 0.2 · 베드 220×220×250 (최소 벽 0.8, 오버행 한계 45°). 출력 방향 +Z, 바닥 z=0.

점수 62/100. 베드 적합. 첫 층 접지 면적 3,120 mm².

1. 얇은 벽 — 리브 4곳 0.6 mm (< 0.8), 위치 (35, 0, 12) 외 3곳 · 심각 · fix: thicken
2. 오버행 — 캔틸레버 10 mm, 서포트 면적 240 mm² · 보통 · fix: overhang_chamfer 또는 방향 변경
3. 작은 구멍 — Ø0.6 × 2 (< 0.8) · 보통 · 재설계
4. 수평 구멍 — Ø6 × 1, 위쪽 찌그러짐 · 낮음 · fix: teardrop

고칠 후보: thicken(1), overhang_chamfer(2), teardrop(4), elephant_foot(바닥 0.3), hole_comp(수직 구멍 +0.2). 번호를 골라 주세요. 방향을 바꾸면 2번이 없어질 수 있으니 순위도 볼까요?
:::

"방향 순위 보여줘" → 후보 표 → "2위로" → 회전 적용 → "다시 검사" 순으로 이어집니다.

## 프로파일

재질(PLA·PETG·ABS·ASA·TPU·Nylon), 노즐, 레이어, 베드 크기를 말합니다. 안 말하면 PLA·0.4·0.2·220×220×250 으로 하고 그렇게 했다고 말합니다. 최소 벽 두께·오버행 한계각·브릿지 최대·구멍 보정은 재질 표의 경험값(슬라이서 기본값·제조사 안내 수준)이라 정밀값이 아닙니다. 우리 프린터 값을 알면 "최소 벽 1.0, 오버행 50°" 처럼 덮어쓰면 됩니다.

## 알아 둘 것

- **자동 수정은 형상을 바꿉니다.** thicken 은 바깥쪽으로 두꺼워져 외형 치수가 변하고, 쐐기는 재료가 늘어 무게가 변합니다. 적용 뒤 다시 검사하고 치수를 확인하세요.
- **곡면 얇은 벽·곡면 오버행은 손으로** 고쳐야 합니다. 자동 수정은 평면만 다룹니다.
- **분할 조각은 Body 밖에 생깁니다.** 접합 핀·다월은 직접 추가합니다.
- **시간·재료 추정은 ±30 %** 수준입니다. 슬라이서보다 거칩니다. 비용은 kg 단가를 주면 계산합니다.
- **FDM 출력물은 층 방향으로 약합니다.** 구조해석까지 하려면 [구조해석](/cadxray/features/08-fem-assembly/)의 한계를 같이 읽으세요.
- Body 가 아닌 객체(STEP 덩어리)는 검사는 되지만 자동 수정은 안 됩니다. 먼저 Body 로 옮기거나 [다시 그리기](/cadxray/features/03-rebuild/).
