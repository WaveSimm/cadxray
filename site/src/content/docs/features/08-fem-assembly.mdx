"이 브라켓에 20 N 걸면 버텨?" 를 FEM 워크벤치에서 하려면 재질·구속·하중·메시·솔버를 손으로 다 만들어야 합니다. AI 는 세 가지(재질, 어디를 잡는지, 어디에 얼마)만 확인하고 한 번에 해석해 안전율을 한 문장으로 말합니다. FreeCAD 1.1.3 에 CalculiX 와 Gmsh 가 동봉돼 있어 따로 설치할 것이 없습니다. 어셈블리는 다른 파일을 가리키는 Link 를 따라가 깨진 곳을 찾습니다.

## 이런 걸 시킬 수 있습니다

| 이렇게 말하면 | 무엇이 나오는가 |
|---|---|
| "PETG 로 뽑아서 바닥 고정, 끝에 20 N 아래로. 버텨?" | 최대 von Mises 응력·위치, 최대 변위, 안전율(항복/최대), 판정 ok·marginal·fail, 3D 뷰 컬러맵 |
| "자중만으로" | 하중 없이 자중 해석 |
| "안전율 2 이상 되게 보강안 줘" | 두께·필렛·리브·재질·하중 후보를 번호 목록으로(기대 안전율·확신도). 자동 적용 없음 |
| "변위 보여줘" | 컬러맵 필드를 변위로, 상위 절점과 면별 최대 |
| "브라켓(강)이랑 커버(PETG) 같이 해석" | 여러 부품, 부품별 재질, 맞닿은 면은 완전 접합 |
| "모터 1,800 rpm 인데 공진 걱정돼" | 고유진동수 모드별 Hz. 1차와 가진 주파수(rpm/60 = 30 Hz) 비교 |
| "어셈블리 무게랑 무게중심" | 부품별 밀도로 합산 |
| "Link 가 빨간데 뭐가 깨졌어?" | 문서 사슬, 깨진 링크(파일 없음), 연결 문서의 Invalid 객체 목록 |

## 대표 프롬프트

```text title="이렇게 말한다"
Body 'Bracket' 을 해석해줘.
- 재질: PETG
- 고정: 바닥면
- 하중: 수직판 위쪽 Ø20 구멍 근처 (60, 40, 60) 면에 −Z 방향 20 N
안전율 목표 2. 결과를 한 문장으로 말하고 등각 컬러맵 보여줘.
안전율이 모자라면 보강 후보를 번호로.
```

:::note[AI 는 이렇게 답합니다]
설정: PETG(재질 표 값), 고정 면 1개(바닥, 면적으로 확인), 힘 면 1개((60, 40, 60) 에서 가장 가까운 면), Gmsh 2차 메시 + CalculiX.

결과: 최대 von Mises 응력이 수직판 밑동 안쪽 모서리에 걸리고, 최대 변위는 끝단. 안전율(항복 / 최대 응력)이 목표 2 에 못 미쳐 marginal. 컬러맵을 첨부합니다.

보강 후보(기대 안전율·확신도는 툴이 계산해 줍니다):
1. 수직판 두께 늘리기 (굽힘 강성)
2. 밑동 안쪽 모서리 필렛 (응력 집중 완화)
3. 뒤쪽 리브 추가
4. 재질 변경

한계: 선형 정적·등방성, FDM 출력물은 층 방향으로 더 약함, 재질 표는 경험값.
:::

"1번" 이라고 하면 AI 가 파라미터를 바꿔 다시 해석하고 새 안전율을 보고합니다.

## 면을 지정하는 법

- 극단 이름: "바닥"·"윗면"·"xmin"·"ymax" — 그 끝에 납작하게 놓인 평면 전부
- 좌표: "(60, 40, 60) 근처 면" — 가장 가까운 면 하나. 구멍·돌기 좌표는 [검사하기](/cadxray/features/05-inspect/)의 구멍 분석이나 bbox 에서 읽습니다
- 법선: "위를 보는 면 전부"

AI 는 설정 뒤 잡힌 면의 면적을 보여 주므로, 의도한 면인지 면적으로 확인합니다.

## 어셈블리 Link 추적

다른 파일의 Body 를 Link 로 끌어온 어셈블리에서 파일을 옮기면 Link 가 "Link not restored" 로 빨개집니다. "뭐가 깨졌어?" 라고 하면 문서 사슬(depth 0 = 이 문서)과 깨진 링크·연결 문서의 Invalid 객체를 번호로 줍니다. 고치는 법은 파일을 제자리에 두거나 새 경로로 열어 부모를 다시 여는 것이고, 고친 뒤 부모 문서에서 재계산 추적으로 확인합니다. Link 배열은 `element_count` 가 인스턴스 수입니다.

## 알아 둘 것

- **선형 정적·등방성만** 입니다. 소성·대변형·접촉·마찰은 없습니다. 여러 부품은 맞닿은 면을 완전 접합으로 풉니다(볼트 체결 모사 아님).
- **좌굴은 지원하지 않습니다.** CalculiX 가 멈추고 메모리가 8 GB 까지 올라 죽는 것이 확인돼 거부합니다.
- **재질 표는 경험값** 입니다(PLA·PETG·ABS·ASA·TPU·NYLON·PMMA·POM·ALUMINUM·STEEL·STAINLESS·BRASS). 정확한 E·항복강도를 알면 숫자로 주세요.
- **특이점 경고**가 있으면 최대값 대신 p99 안전율을 봅니다. 날카로운 모서리에 응력이 무한히 몰리는 것은 실물이 아니라 해석의 성질입니다.
- **"nonpositive jacobian" 으로 실패**하면 메시가 찌그러진 것 — AI 가 메시 크기를 줄여 다시 합니다. 절점이 30만 개를 넘으면 반대로 키웁니다.
- **해석 객체는 문서에 남습니다.** 같은 이름으로 다시 설정하면 지우고 새로 만듭니다.
- 결과 절점 좌표는 변형 전 좌표입니다.

|---|---|
