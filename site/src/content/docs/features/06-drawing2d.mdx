모델이 끝나면 가공업체에 보낼 도면이 필요합니다. TechDraw 에서 페이지를 만들고 뷰를 놓고 치수를 하나씩 찍는 일을 말로 시킵니다. 축척은 페이지에 맞춰 자동으로 잡히고, 치수 값은 모델에서 재므로 손으로 적을 때 생기는 오타가 없습니다.

## 이런 걸 시킬 수 있습니다

| 이렇게 말하면 | 무엇이 나오는가 |
|---|---|
| "이거 2D 도면으로 뽑아줘" | ISO A3 가로 템플릿에 정면·우측·평면(+등각) 뷰, 자동 축척, PDF |
| "길이·폭·높이·구멍 지름 치수 넣어줘" | 모델 정점·실루엣·원을 참조하는 치수. 값은 모델에서 잰 것 |
| "구멍 부분 상세 뷰 A, 5배" | 정면 뷰의 한 점을 중심으로 상세 뷰(반지름·축척 지정) |
| "주석에 '모따기 C0.5, 전면 아노다이징' 넣어" | 페이지 주석 |
| "표제란에 품명·도번·축척 채워" | ISO 템플릿의 편집 가능 텍스트 |
| "도면에 치수 값이 모델이랑 맞아?" | 페이지의 뷰·치수 값·상태(Touched/Invalid)를 읽어 대조 |
| "어셈블리 전체 도면" | Link 그룹을 하나로 묶어 뷰 생성. Link 27개 어셈블리 5뷰·치수 13개가 87초 |

## 대표 프롬프트

```text title="이렇게 말한다"
Body 'Bracket' 으로 A3 도면 만들어줘.
- 뷰: 정면, 우측, 평면, 등각
- 치수: 전체 길이(X), 전체 폭(Y), 높이(Z), 구멍 4개 중 하나의 지름, 구멍 피치(X 방향)
- 주석: "치수 단위 mm, 미표기 모따기 C0.5"
- 표제란: 품명 브라켓, 도번 OT-BR-001, 재질 AL6061
PDF 로 D:\work\ 에 내보내고, 치수 값이 모델과 같은지 확인해서 표로 보여줘.
```

:::note[AI 는 이렇게 답합니다]
페이지 `Page` 를 만들었습니다(ISO A3 가로, 축척 1:2 자동). 뷰 4개, 치수 5개, 주석 1개, 표제란 채움.

| 치수 | 종류 | 값 | 모델 값 | 상태 |
|---|---|---|---|---|
| 전체 길이 | DistanceX | 120.00 | 120.00 | Valid |
| 전체 폭 | DistanceY | 80.00 | 80.00 | Valid |
| 높이 | DistanceY(우측) | 60.00 | 60.00 | Valid |
| 구멍 지름 | Diameter | Ø6.60 | 6.60 | Valid |
| 구멍 피치 | DistanceX | 96.00 | 96.00 | Valid |

PDF: D:\work\Bracket.pdf. 치수 두 개가 뷰 이름과 겹쳐 자동으로 밀어냈습니다. 배치가 마음에 안 들면 GUI 에서 끌어 옮기세요.
:::

## 치수를 어떻게 지정하나

AI 는 치수를 **모델의 정점 좌표**로 찾습니다. 그래서 "전체 길이" 같은 말은 bbox 에서, "구멍 지름" 은 구멍 분석 값에서 좌표를 읽어 넣습니다. 원통 실루엣 사이 거리(축 방향 두 위치)나 원 지름도 됩니다. 정점을 못 찾은 치수는 그 하나만 건너뛰고 경고에 적습니다. 상세 뷰 안의 치수도 같은 방식입니다.

## 알아 둘 것

- **기본 배치는 대략입니다.** 뷰끼리 겹치거나 치수가 몰리면 AI 에 "정면 뷰 오른쪽으로 40 옮겨" 라고 하거나 GUI 에서 끕니다. 겹친 치수는 자동으로 밀어내지만 완벽하지 않습니다.
- **뷰의 모서리 수가 0 이면** 소스가 빈 것입니다. 어셈블리면 그룹 이름을, Body 면 Body 이름을 정확히 말해 줍니다.
- **큰 어셈블리는 투영에 1분 넘게** 걸립니다. AI 가 기다린다고 말하면 그대로 두세요.
- **치수는 뷰 축을 따릅니다**(Projected). 경사면 길이가 필요하면 "Distance" 로, 축 방향은 "DistanceX/Y" 로 말하면 정확합니다.
- **PDF 는 도면 페이지 창이 열려야 나옵니다.** GUI 없이 돌리면 페이지는 만들지만 내보내기는 건너뜁니다.
- 축척은 1:1·1:2·1:5·1:10·1:20·1:50·1:100 중에서 뷰가 페이지의 60 % 에 들어가게 고릅니다. 지정하려면 "축척 1:1 로" 라고 말합니다.
