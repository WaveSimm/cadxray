벤더 STEP 은 면 덩어리라 구멍 지름 하나를 바꾸려 해도 손댈 피처가 없습니다. STL 은 삼각형뿐이라 더합니다. AI 에 "다시 그려줘" 라고 하면 원본을 재서 스케치·Pad·Groove·Pocket·챔퍼로 같은 모양을 새 Body 에 쌓고, 원본과 차집합을 떠서 어디가 틀렸는지 알려 줍니다. STEP 이든 STL 이든 절차는 같고, 검증 방법만 다릅니다.

## 이런 걸 시킬 수 있습니다

| 이렇게 말하면 | 무엇이 나오는가 |
|---|---|
| "이 STEP 부품 파라메트릭으로 다시 만들어줘" | 면 분류 → 띠 높이 → 단면 트레이스 → 피처 쌓기 → 원본과 차집합 비교. 클램프 조(44면)는 피처 12개, 부피 차 0.0004 % |
| "이 STL 다시 그려줘" | 참고 메시를 투명으로 띄우고 띠별 단면 원을 피팅해 같은 절차. 스풀 가이드(5,758면)는 정점 전부 0.03 mm 안, 부피 차 0.014 %, 수나사 M44.5×2 포함 |
| "원본이랑 얼마나 다른지 봐줘" | STEP: 부피·면적·bbox 차 + 빠진/남는 조각의 위치와 판정(identical·match·different). STL: 편차 max·p95 와 가장 튀는 점 |
| "이 STEP 어셈블리 80개 전부 다시 만들어줘" | 같은 부품은 종류당 Body 하나, 나머지 자리는 Link 인스턴스. 20종·80개를 3.5분에 배치·접지, 간섭 0 |
| "원본 위에 구멍만 추가하고 싶어" | 다시 그리지 않고 원본을 BaseFeature 로 넣은 Body 에 Pocket 만 쌓음(자유곡면이 많을 때) |

## 대표 프롬프트

```text title="이렇게 말한다"
Unnamed 문서에 열려 있는 Part__Feature004 (벤더 클램프 조) 를 파라메트릭 Body 로 다시 만들어줘.
새 문서 jaw_rebuild 에 만들고,
- 먼저 면 분류 결과(주축·띠 높이·반지름)를 보여주고
- 띠마다 어떤 피처로 볼 건지 목록으로 말한 다음
- 내가 확인하면 쌓아.
다 만들면 원본과 비교해서 판정과 틀린 조각 위치를 알려줘.
```

:::note[AI 는 이렇게 답합니다]
면 44개를 분류했습니다. 주축 Z, 판정 prismatic. BSpline 면 8개는 실제로는 원뿔(반각 59.63°)입니다. 원통 반지름은 35 / 33.620391 / 17.75 / 16.12127, 띠 경계 z 는 53.68 · 57.39 · 57.97 · 65.39 · 65.97 · 69.68 입니다.

피처 계획 12개: PadBand1(아래 띠) → PadMid → PadBand2(위 띠, 겹치게) → GrooveDovetail(회전 홈) → PadLip(360° 절삭이 깎은 귀 복원) → PocketHoles(Ø3.4 관통, 카운터보어 Ø5.6×4) → PocketPins(Ø2.2×5, 2개) → ChamferHoles(0.5) …

확인해 주시면 쌓겠습니다.
:::

확인 뒤 AI 가 쌓고 비교하면 "verdict identical, 부피 차 +0.035 mm³(0.0004 %), 스케치 12개 전부 DoF 0" 같은 보고가 옵니다. `different` 가 나오면 빠진 조각(`missing`)과 남는 조각(`extra`)의 bbox 를 주므로 그 자리의 피처만 고칩니다.

## 절차가 이렇게 돕니다

1. **면 분류** — 면마다 평면·원통·원뿔·구·자유곡면을 판정합니다. STEP 에 BSpline 으로 들어온 면도 표본을 찍어 맞춰 보므로 "가짜 자유곡면" 이 걸러집니다. 자유곡면이 정말 많으면 AI 가 하이브리드(원본 위에 피처)를 제안합니다.
2. **띠 높이** — 축을 따라 단면이 바뀌는 높이(레벨)를 읽습니다. 기준점만 정점에서 읽고 나머지는 설계값으로 정리합니다.
3. **단면 트레이스** — 띠마다 단면 윤곽을 스케치 선분·호·원으로 뽑아 Pad. 좌표가 대화를 오가지 않아 토큰을 아낍니다.
4. **회전 홈·구멍·챔퍼** — 회전 절삭이 깎아 버린 귀는 다시 Pad 로 메웁니다. 구멍은 구멍 분석 값으로, 챔퍼는 모서리 반지름 필터로.
5. **비교** — STEP 은 퍼지 차집합, STL 은 법선 광선 편차. 어느 쪽이든 "어디가" 틀렸는지 좌표로 나옵니다.

## 알아 둘 것

- **반지름은 측정값 그대로 씁니다.** 33.620391 을 33.6204 로 반올림하면 겹친 면이 9e-6 어긋나 합치기에서 0.6 mm³ 를 잃습니다. AI 가 이상한 소수를 파라미터에 넣어도 그대로 두세요. 설계값으로 정리하는 것은 기준점 정도입니다.
- **STL 은 부피를 믿기 전에 닫힌 메시인지 봅니다.** AI 가 `is_solid` 가 false 라고 하면 편차 비교만 믿고 부피 차는 참고만 합니다.
- **어셈블리는 종류당 하나만 만듭니다.** STEP 의 Placement 는 인스턴스 위치가 아니라서 AI 가 형상에서 강체 변환을 찾아 Link 로 놓습니다. 거울상 인스턴스가 섞여 있으면 따로 알려 줍니다.
- **나사는 STEP 에 없습니다.** 구멍 지름으로 M3 탭·M6 관통을 "추정" 만 합니다. STL 에 실제 나사산이 있으면 피치·외경·골을 읽어 나선으로 다시 만듭니다.
- **떨어진 Pad 는 한 Body 에 못 넣습니다.** 아래 띠 → 가운데 → 위 띠 순으로 겹치게 쌓는 이유입니다.
- 저장은 "저장해줘" 라고 해야 합니다.
