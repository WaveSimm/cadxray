## Setup

1. Launch FreeCAD 1.1.3. You want `[CAD X-ray] 서버 시작 http://127.0.0.1:9877 (툴 36개)` in the Report view.
2. Download the PDF into a folder with a short path (for example `C:\cad\02-cover-drawing.pdf`). Keep the filename exactly as the release gives it.
3. In PowerShell, move to that folder and type `claude` to open your AI tool (Codex and Gemini CLI open in the same folder).
4. Close any other FreeCAD documents. That cuts down on the AI asking which document to build in.

## Steps

### 1. Have it read the drawing and give you a table first

```text title="Say this"
Read C:\cad\02-cover-drawing.pdf and show me a table per plate of «values read / values assumed / basis» before anything else.
```

**What the AI does** — reads the PDF's vector elements (a circle is a path of four curves, a rectangle is `re`) and its dimension text, converting at 1 pt = 25.4/72 mm. Three things should appear in the table without being asked for: the scale (the dimension text 36.38 matching the 36.38 between circle centres means 1:1), anywhere the written dimension and the drawn position disagree (the first hole of drawing 2, off by 0.4 / 2.2 mm), and values it had to assume because the drawing lacks them (plate thickness, Ø7 hole height).

:::note[What the AI says back]
Two drawings on one page. DATA LOGGER: outer rectangle 224.28×169.37, inner rectangle 206.70×151.82 (8.79 in from each edge, the dimension reference line). Eight Ø18 holes (x from 27.40 in 4 columns at 36.38 spacing × y 23.80 / 74.20, 2 rows), two Ø25, four Ø7. Sensor-extension logger: ten Ø18. Scale 1:1. Assumed: no plate thickness on the drawing, so 3; no Ø7 height, so measured 114.98 from the vectors. On the sensor plate the first hole's written dimension and drawn position differ by 0.4 / 2.2 mm. The connector flange rectangle and the four small holes inside it have no dimensions. How should I handle these?
:::

**How to check** — the table should show a plate size of 224.28×169.37, hole types Ø18 · Ø25 · Ø7, and exactly two items marked "assumed": the thickness and the Ø7 height. If it says the scale is not 1:1, your PDF may be a reduced print; get the original file again.

:::tip[Why not have it build straight away]
The drawing gives no plate thickness and no height for the antenna holes. An AI can settle such values on its own and move on, and spotting a wrong assumption in a 3D model is much harder than spotting it in a table. Every practice that builds from a file follows the same order: «table → answer → build».
:::

### 2. Answer the assumptions and have it build

```text title="Say this"
Written dimensions win, thickness 3 as a parameter, don't machine the flange rectangle or the small holes inside it. Build both plates like that: Body Cover_DataLogger in document cover_logger, Body Cover_SensorExt in document cover_sensor.
```

**What the AI does** — for the data logger plate it stacks four sketches (the plate rectangle plus three hole groups) with one Pad and three Pockets, for the sensor-extension plate one Pad and one Pocket, recomputing after each feature to confirm validity. Hole centres are the inner-rectangle dimensions plus 8.79; the four antenna hole x coordinates (120.40 / 138.10 / 165.30 / 183.00) work back from the inner rectangle width 206.70 minus 23.70, at spacings of 17.70 / 27.20 / 17.70. The sensor plate's x coordinates come out as five columns: 27.40 / 65.12 / 102.92 / 140.72 / 178.52. The dimensions go into the `Params` spreadsheet as aliases, so changing the thickness later brings everything with it.

:::note[What the AI says back]
Cover_DataLogger done. PadPlate → Pocket_D18 (8) → Pocket_D25 (2) → Pocket_D7 (4). All four sketches at DoF 0, shape valid, volume 104,445 mm³, bbox 0–224.28 × 0–169.37 × 0–3.0. Params: plate_w, plate_h, inset, thickness, hole_d18, hole_d25, hole_d7.
Cover_SensorExt done. PadPlate → Pocket_D18 (10). DoF 0, valid, volume 106,325 mm³.
:::

**How to check** — in the model tree, `Cover_DataLogger` should contain `PadPlate`, `Pocket_D18`, `Pocket_D25` and `Pocket_D7`, and `Cover_SensorExt` should contain `PadPlate` and `Pocket_D18`, with nothing marked red. Open the `Params` sheet, change `thickness` to 5 and recompute (F5 or Ctrl+R) to see the plate thicken. Then put it back to 3. Count the sensor plate's holes from above (number key 2) and confirm there are ten.

### 3. Look, then save

```text title="Say this"
Show me a top view of both documents. If they look right, save them to C:\cad\cover_logger.FCStd and C:\cad\cover_sensor.FCStd.
```

**What the AI does** — puts the screenshots in the conversation and saves only after you say they are right. The rule is that the AI never saves a document until told to.

**How to check** — overlay the hole layout in the screenshot on the drawing. In particular, check that the first hole of the sensor plate sits at the "written dimension" position.

## Checking your result

| Criterion | Value |
|---|---|
| Plate bbox | 224.28 × 169.37 × 3.0 |
| Sketch DoF | all 0 |
| Shape validity | valid |
| Feature count | data logger 4 (Pad 1 + Pocket 3), sensor-extension 2 (Pad 1 + Pocket 1) |
| Parameters | `Params` holds plate_w, plate_h, inset, thickness, hole_d18 (+ hole_d25, hole_d7) |

There is no original STEP in this exercise, so there is no volume comparison. If the bbox, the hole count and the screenshot match the drawing, you succeeded.

## When it doesn't work

- **"I can't read the PDF"** — a scan (an image PDF) has no vectors and this approach will not work. Read the dimensions out as in Exercise 1, or get the original CAD drawing.
- **It says the scale is not 1:1** — the PDF was reduced for printing. The AI tells you the ratio between the dimension text and the drawn length, so say "convert at that ratio and carry on".
- **The holes land outside the plate** — the inner-rectangle datum (the 8.79 offset) got dropped. Say "check you added the 8.79 inset to the hole coordinates".
- **The AI keeps asking because several documents are open** — just give it the name. Naming it from the start ("in a new document cover_logger") avoids the question.
- **The plate built but a feature is red** — say "find the cause of the red feature and fix it" (see Exercise 6).

## Going further

1. Change `Params.thickness` to 2 and recompute. Check the hole Pockets still go through.
2. Ask for 0.5 mm chamfers on the four Ø7 antenna holes. Stating the edge condition is enough: "0.5 chamfer on the top edge of the Ø7 holes".
3. Put both plates in one document and produce a 2D drawing (Exercise 7).
