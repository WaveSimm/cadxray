모델링은 한 문장으로 끝나지 않습니다. AI 가 묻고, 후보를 내고, 사람이 고르는 짧은 왕복이 몇 번 이어집니다. 자주 나오는 왕복 여섯 가지입니다.

## 1. 되물음에 답하기

AI 가 빠진 정보를 물으면 그것만 답합니다. 처음 문장을 다시 쓸 필요 없습니다.

:::note[AI 는 이렇게 답합니다]
문서가 두 개 열려 있습니다(Unnamed, bracket_v2). 어느 문서에서 작업할까요?
:::

```text title="이렇게 말한다"
bracket_v2.
```

## 2. 번호 고르기

스케치 수정, 출력 방향, 보강 방법은 AI 가 **번호 목록**으로 내놓고 멈춥니다. 추천 표시가 있어도 자동으로 적용하지 않습니다.

:::note[AI 는 이렇게 답합니다]
Sketch003 은 치수 두 개가 충돌합니다(제약 12번 길이 40, 제약 15번 길이 42). 고칠 후보:
1. 제약 12번 삭제 → 자유도 0 (추천)
2. 제약 15번 삭제 → 자유도 0
3. Line5 끝점과 Arc2 시작점 잇기 → 열린 끝점 2→0
둘 중 하나만 고르세요. 어느 것으로 할까요?
:::

```text title="이렇게 말한다"
1번이랑 3번.
```

"추천대로" 라고 해도 됩니다. 단, 치수를 새로 거는 후보(현재 값을 굳히는 것)는 그 값이 설계 치수인지 먼저 봅니다.

## 3. 가정을 표로 받기

도면에 없는 값을 AI 가 정했을 때는 표로 받아 확인합니다. 종합 실습(철봉 프레임)에서 특히 중요합니다.

```text title="이렇게 말한다"
만들기 전에, 도면에 없어서 네가 가정한 값을 표로 먼저 보여줘. 확인하고 진행할게.
```

:::note[AI 는 이렇게 답합니다]
| 항목 | 도면 | 가정 | 근거 |
|---|---|---|---|
| 판 두께 | 없음 | 3 mm | 커버 판 관례 |
| 안테나 구멍 높이 | 치수 없음 | 114.98 | 벡터에서 측정 |
진행할까요?
:::

```text title="이렇게 말한다"
두께는 2 로. 나머지는 그대로.
```

## 4. 단계 나누기

긴 작업은 FreeCAD 를 멈추게 할 수 있고, 중간에 틀리면 찾기 어렵습니다. 피처 서너 개, 또는 "판까지" · "구멍까지" 식으로 끊습니다.

```text title="이렇게 말한다"
먼저 판만 만들고 보여줘. 확인하면 구멍을 뚫자.
```

STEP·STL 을 다시 그릴 때도 마찬가지입니다. "면 분류만 먼저", "단면 높이만 먼저", "아래 띠만 먼저" 로 나눕니다.

## 5. 되돌리기와 확인

고친 뒤에는 무엇이 풀렸고 무엇이 새로 깨졌는지 AI 가 재계산으로 확인합니다. 결과가 나빠졌으면 되돌리게 합니다.

```text title="이렇게 말한다"
방금 수정으로 새로 깨진 게 있어? 있으면 되돌려.
```

스케치 수정 후보는 적용해서 나빠지면 AI 가 스스로 되돌립니다. 그 밖의 수정은 FreeCAD 의 편집 → 실행 취소(Ctrl+Z)도 됩니다.

## 6. 저장

AI 는 시키기 전엔 저장하지 않습니다. 기존 파일을 덮어쓰는 것은 한 번 더 확인합니다.

```text title="이렇게 말한다"
D:\models\cover_v2.FCStd 로 저장해. 같은 이름이 있으면 덮어써.
```

## 보여 달라고 하기

| 보고 싶은 것 | 말 |
|---|---|
| 지금 모양 | "iso 로 보여줘" (front, top, right 등 12방향) |
| 구조 | "트리 구조 요약해줘" |
| 어떤 값이 어디서 오는지 | "Pad 의 Length 가 어디서 오는 값이야?" |
| 원본과 얼마나 다른지 | "원본이랑 비교해서 어디가 다른지 알려줘" |
| 수치 | "부피, 무게중심, 자유도 알려줘" |

## 대화가 길어졌을 때

한 세션에서 모델 두세 개를 만들면 AI 가 앞의 문서와 헷갈리기 시작합니다. 새 모델은 새 대화(`/clear` 또는 툴 재시작)에서 시작하고 문서 이름을 다시 말합니다.
