AI 는 FreeCAD 안을 직접 읽지만 **머릿속은 못 읽습니다.** 빠진 것은 되묻거나 가정합니다. 되묻는 횟수를 줄이는 방법은 처음부터 다섯 가지를 넣는 것입니다.

## 1. 대상 — 어느 문서, 어느 객체

문서가 하나면 안 써도 됩니다. 둘 이상이면 이름을 씁니다. 객체는 트리에 보이는 **Label** 로 부릅니다.

```text title="이렇게 말한다"
문서 bracket_v2 의 Body 에서 Sketch003 이 왜 빨간지 봐줘.
```

## 2. 치수와 단위 — 숫자는 전부

길이는 mm, 각도는 도. 판이면 가로×세로×두께, 구멍이면 지름·개수·위치(모서리에서 몇 mm, 또는 피치). "적당히" 는 되묻습니다.

```text title="이렇게 말한다"
100×60 두께 5 판. 네 모서리에서 10 안쪽에 Ø6.6 관통 구멍 4개.
```

## 3. 기준 — 어느 평면, 어느 방향, 무엇을 기준으로

XY 평면에 그려 +Z 로 올릴지, 앞면이 어느 쪽인지. 도면에서 옮길 때는 원점을 어디로 잡을지. 안 말하면 AI 가 정하고 알려 줍니다. 대개 XY 에 그려 위로 올립니다.

```text title="이렇게 말한다"
XY 평면에 그리고 위로 올려. 원점은 판의 왼쪽 아래 모서리.
```

## 4. 확인 — 무엇을 보여 달라고 할지

AI 는 기본으로 재계산 결과(오류 없음)와 스크린샷을 보여 줍니다. 더 보고 싶은 것을 말합니다.

```text title="이렇게 말한다"
끝나면 iso 스크린샷이랑 부피, 스케치 자유도 알려줘.
```

## 5. 저장 — 시킬 때만

AI 는 시키기 전엔 저장하지 않습니다. 경로까지 말합니다.

```text title="이렇게 말한다"
D:\models\plate.FCStd 로 저장해.
```

## 다섯 개를 한 문장으로

```text title="이렇게 말한다"
새 문서에 100×60 두께 5 판을 XY 평면에 그려 위로 올리고, 네 모서리에서 10 안쪽에 Ø6.6 관통 구멍 4개를 뚫어줘. 치수는 스프레드시트 Params 에 넣고, 끝나면 iso 스크린샷과 자유도 보여줘. 저장은 아직 하지 마.
```

:::note[AI 는 이렇게 답합니다]
Body 하나에 Pad(판) + Pocket(구멍 4개) 을 만들었습니다. 스케치 2개 모두 자유도 0, 부피 29,863 mm³. Params 에 width·height·thickness·hole_d·margin 5개. (스크린샷)
:::

## 빠졌을 때 생기는 일

| 빠진 것 | AI 가 하는 일 |
|---|---|
| 두께 | 되묻거나 "3 mm 로 가정합니다" 라고 말하고 진행 |
| 구멍 위치 | 되묻음. 도면에서 옮길 때는 벡터에서 측정하고 그렇게 말함 |
| 평면·방향 | XY 에 그려 +Z 로. 결과가 뒤집혀 보이면 "Y 축으로 뒤집어" |
| 문서 이름 (여러 개 열림) | 어느 문서인지 되묻음 |
| 재질 (해석·프린트) | PLA 로 가정하고 그렇게 말함 |

빠진 것을 AI 가 가정했다면 답에 "가정" 이라는 말이 있는지 봅니다. 틀렸으면 그 자리에서 고쳐 말합니다.

```text title="이렇게 말한다"
두께는 3 이 아니라 5 야. 다시 해줘.
```

## 하지 말 것

- **한 문장에 열 가지.** 판 만들고, 구멍 뚫고, 필렛 넣고, 도면 뽑고, 프린트 검사까지 한 번에 시키면 중간에 틀려도 어디서 틀렸는지 모릅니다. 서너 개씩 끊습니다.
- **좌표를 직접 불러 주기.** STEP·STL 을 다시 그릴 때 정점 좌표를 받아 적어 다시 넣지 마세요. AI 가 원본을 직접 트레이스합니다. "원본 단면을 그대로 따라 그려" 로 충분합니다.
- **반올림 요구.** "반지름 33.62 로 깔끔하게" 는 원본과 어긋나 부피를 잃습니다. 측정값 그대로 두게 합니다.
