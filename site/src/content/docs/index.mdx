## 이 사이트는

FreeCAD 1.1.3 에 **cadxray** 라는 연결 장치를 붙이면 Claude Code·Codex CLI·Gemini CLI 같은 AI 코딩 툴이 열려 있는 FreeCAD 문서를 직접 읽고 만들고 고칩니다. 이 사이트는 그 장치를 설명하는 곳이 아니라, **그것으로 3D 모델을 말로 만드는 법**을 배우는 곳입니다. 페이지마다 «이렇게 말한다» 상자의 문장을 복사해 AI 에 붙여 넣으면 됩니다.

## 권하는 순서

1. **설치**와 **AI 툴 연결**을 끝냅니다. 30분이면 됩니다.
2. **실습 1** 로 판에 구멍 4개를 뚫어 봅니다. 모델이 나오면 준비는 끝입니다.
3. 자기 일과 가까운 실습을 고릅니다. 도면이 있으면 실습 2·3·10, 벤더 부품이 있으면 4·5, 기존 모델이 자꾸 빨개지면 6.
4. 막히면 **프롬프트 작성법**을 읽고 문장을 고쳐 다시 시킵니다. 질문은 [GitHub Issues](https://github.com/WaveSimm/cadxray/issues) 에 남깁니다.

## 알아 둘 것

- 모든 통신은 내 PC 안(127.0.0.1)에서만 오갑니다. 모델 파일이 외부로 나가지 않습니다. 다만 AI 툴 자체는 대화 내용을 각 회사 서버로 보냅니다.
- AI 는 파일을 **시키기 전엔 저장하지 않습니다**. 마음에 들면 "저장해" 라고 말합니다.
- 수정 후보는 항상 번호 목록으로 보여 주고, 고른 것만 적용합니다. 자동으로 고치지 않습니다.
- 검증은 FreeCAD 1.1.3 · Windows 기준입니다. macOS·Linux 는 설치 경로만 다르고 절차는 같습니다.
