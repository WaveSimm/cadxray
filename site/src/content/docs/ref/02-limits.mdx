## 못 하는 것

- **좌굴 해석.** 구조해석은 선형 정적과 고유진동수만. 큰 변형·소성·접촉·마찰·볼트 체결은 계산하지 않습니다.
- **슬라이싱.** 3D 프린트 검토는 설계 단계 검사와 수정입니다. G-code 는 슬라이서에서.
- **STL 의 구멍·간섭 직접 분석.** 메시는 면·솔리드가 없어 구멍 세기·간섭 계산은 안 됩니다. 먼저 다시 그려서 Body 로 만든 뒤 합니다.
- **자동 피처 인식.** "이 STEP 을 알아서 피처로" 는 없습니다. 어떤 피처로 볼지는 AI 가 측정값을 보고 정하고, 사람이 확인합니다.
- **원격 FreeCAD.** 같은 PC 의 FreeCAD 만. 127.0.0.1 전용입니다.

## 추정에 그치는 것

- **구멍 관통 여부.** 구멍 양 끝이 재료 밖인지로 판단하는 휴리스틱. 포켓 바닥으로 뚫린 구멍은 관통으로 보일 수 있습니다.
- **나사 규격.** STEP 에 나사산이 없어 지름을 ISO 미터나사 표와 대조해 «M6 관통 / M3 탭 드릴» 식으로 추정만 합니다.
- **프린트 재질 표·시간·비용.** 경험값입니다. AI 답의 warnings 를 그대로 봅니다.
- **FEM 재질 표.** 경험값. FDM 출력물은 층 방향으로 더 약합니다. 안전율은 등방성 가정입니다.

## 시간이 오래 걸리는 것

| 작업 | 시간 | 대처 |
|---|---|---|
| STL 을 솔리드로 바꿔 불리언 비교 | 10분 이상, 중단 불가 | 메시 이름 그대로 비교(기본) |
| Link 수십 개 어셈블리 도면 투영 | 1분 이상 | 기다림 |
| 80부품 간섭 전수 | 6.5초 | 정상 |
| 긴 Python 코드 실행 | 끝날 때까지 FreeCAD 멈춤 | 단계로 나눠 시킴 |

## 지켜야 할 것

1. **FreeCAD 는 하나만.** 두 개 켜면 포트 충돌.
2. **저장은 사람이.** AI 는 시키기 전엔 저장하지 않습니다. 시킬 때 경로를 말합니다.
3. **후보는 사람이 고른다.** 추천 표시는 참고입니다. 특히 «현재 값을 치수로 굳히기» 후보는 설계 치수인지 확인.
4. **반올림 금지.** 다시 그릴 때 반지름·중심은 측정값 그대로. 반올림하면 면이 어긋나 부피를 잃습니다.
5. **작업 중인 파일은 백업.** 실습은 사본으로. 원본 STEP·FCStd 는 다른 폴더에.
6. **대화 내용은 외부로 갑니다.** 모델 파일은 PC 안에 있지만, AI 툴은 대화(프롬프트·AI 가 읽은 수치·스크린샷)를 각 회사 서버로 보냅니다. 대외비 도면은 회사 방침을 먼저 확인합니다.

## 검증 범위

cadxray 는 FreeCAD 1.1.3 · Windows 에서 검증됐습니다. 이 사이트의 실습도 그 기준입니다. macOS·Linux 는 설치 경로만 다르고 절차는 같지만 실검증은 하지 않았습니다. 1.0.x 는 일부 API 가 달라(스케치 점 이동 명령 등) AI 가 버전을 보고 맞춥니다.
