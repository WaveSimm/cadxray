AI 의 답에 자주 나오는 말입니다. FreeCAD 를 처음 쓰는 사람을 위한 최소한의 뜻입니다.

| 용어 | 뜻 |
|---|---|
| **Body** | PartDesign 의 부품 하나. 그 안에 스케치와 피처가 순서대로 쌓입니다. "Body 를 만들어" 는 부품 하나를 새로 시작한다는 뜻 |
| **Sketch(스케치)** | 평면 위의 2D 그림. 선·호·원과 제약으로 이루어집니다. Pad·Pocket 의 재료 |
| **Pad** | 스케치를 두께만큼 밀어 올려 재료를 더함 |
| **Pocket** | 스케치 모양으로 재료를 파냄. 구멍·홈 |
| **Groove / Revolution** | 축을 중심으로 회전시켜 재료를 파냄 / 더함. 원통·홈·립 |
| **Fillet / Chamfer** | 모서리를 둥글게 / 비스듬히 깎음. R2, C0.5 |
| **Helix(나선)** | 나사·나선 홈. 피치·높이·방향 |
| **피처(Feature)** | Pad·Pocket 같은 한 단계. Body 트리에 순서대로 보임 |
| **Tip** | Body 에서 «지금 결과»를 가리키는 피처. 보통 맨 마지막 |
| **제약(Constraint)** | 스케치 요소의 위치·크기를 정하는 조건. 수평·수직·일치·길이·지름·같음 등. 번호는 제약 패널과 같음 |
| **자유도(DoF)** | 제약으로 아직 못 박히지 않은 움직임의 수. **0 이면 완전 구속**(초록). 남으면 드래그하면 움직임 |
| **충돌(conflicting)** | 서로 모순되는 제약(길이 40 과 42 를 같은 선에). 스케치가 빨개짐 |
| **중복(redundant)** | 같은 뜻의 제약이 둘. 해는 있지만 경고 |
| **열린 끝점(open vertex)** | 닫혀야 할 윤곽이 벌어진 곳. 한 군데당 끝점 2개. Pad 가 실패하는 흔한 원인 |
| **재계산(recompute)** | 바뀐 것을 반영해 형상을 다시 계산. 실패한 객체는 Invalid(빨강) |
| **Placement** | 객체의 위치·자세(이동+회전) |
| **Link** | 다른 Body 나 다른 파일의 부품을 참조하는 객체. 같은 부품을 여러 자리에 놓을 때. 파일이 없으면 «깨진 링크» |
| **BaseFeature** | STEP 으로 받은 덩어리를 Body 의 바탕으로 넣은 것. 원본은 못 고치지만 위에 Pocket 을 덧붙일 수 있음 |
| **Params(Spreadsheet)** | AI 가 치수를 이름 붙여 넣는 표. `thickness` 를 바꾸면 Pad 가 따라 바뀜 |
| **STEP** | 벤더가 주는 정확한 솔리드 형식. 면·모서리가 있어 구멍·간섭 분석 가능 |
| **STL / OBJ / 3MF** | 삼각형 메시. 면·솔리드가 없어 «다시 그려야» 분석 가능 |
| **bbox** | 객체를 감싸는 상자의 최소·최대 좌표. 크기 확인용 |
| **차집합(cut)** | 원본에 있고 재구성에 없는 조각(missing) / 그 반대(extra). 어디가 틀렸는지 |
| **verdict** | 비교 판정. identical(0.001 % 미만) / match(0.1 % 미만) / different |
| **von Mises 응력** | 재료가 받는 등가 응력. 항복강도와 비교해 안전율 = 항복 / 최대 응력 |
| **TechDraw** | FreeCAD 의 2D 도면 워크벤치. 페이지·뷰·치수·표제란 |
| **워크벤치** | FreeCAD 의 작업 모드 묶음. Part Design, Sketcher, TechDraw, FEM, CAD X-ray |
