Google 의 터미널 코딩 툴입니다. 등록 명령과 규칙 파일 이름(GEMINI.md)만 다르고 나머지는 같습니다.

## 설치

Google 안내대로 Gemini CLI 를 설치하고 로그인합니다. 확인:

```powershell
gemini --version
```

## 등록

```powershell title="터미널"
gemini mcp add cadxray uvx --from git+https://github.com/WaveSimm/cadxray#subdirectory=bridge cadxray
```

Codex 와 달리 `--` 구분자가 없습니다. 또는 `~/.gemini/settings.json` 에 직접 적습니다.

```json title="~/.gemini/settings.json"
{
  "mcpServers": {
    "cadxray": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/WaveSimm/cadxray#subdirectory=bridge", "cadxray"]
    }
  }
}
```

다른 MCP 가 이미 있으면 `mcpServers` 안에 `"cadxray"` 항목만 추가합니다. 포트를 바꿨으면 `args` 끝에 `"--port", "9878"`.

## 연결 확인

FreeCAD 를 켠 상태에서 `gemini` 를 열고 `/mcp` 를 입력합니다. `cadxray` 와 툴 목록이 나오면 됩니다.

```text title="이렇게 말한다"
cadxray 로 FreeCAD 에 연결되는지 확인하고 버전 알려줘.
```

## 규칙 파일 — GEMINI.md

작업 폴더의 `GEMINI.md` 를 읽습니다. cadxray 의 CLAUDE.md 를 그 이름으로 저장합니다.

```powershell title="터미널"
mkdir C:\cad-work
cd C:\cad-work
curl -o GEMINI.md https://raw.githubusercontent.com/WaveSimm/cadxray/master/CLAUDE.md
gemini
```

## 이 툴에서 다른 점

- **스크린샷**: 이미지 표시는 툴 버전에 따라 다릅니다. 안 보이면 FreeCAD 화면을 직접 봅니다.
- **첫 연결이 느리면** 브릿지를 내려받는 10–30초입니다. 툴이 안 보이면 `/mcp` 를 한 번 더 부릅니다.
- 프롬프트 문장은 공통입니다. [프롬프트 작성법](/cadxray/prompt/01-structure/).

## 확인 표

| | 명령 | 기대 결과 |
|---|---|---|
| 등록 | `/mcp` | `cadxray` + 툴 36개 |
| 연결 | 첫 대화 | FreeCAD 1.1.3 |
| 규칙 | 작업 폴더 | `GEMINI.md` 있음 |
