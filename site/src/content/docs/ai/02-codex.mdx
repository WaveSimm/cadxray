OpenAI 의 터미널 코딩 툴입니다. cadxray 브릿지는 표준 MCP 라서 같은 명령으로 붙습니다. 다른 점은 등록 명령, 규칙 파일 이름(AGENTS.md), 그리고 스크린샷 표시 여부입니다.

## 설치

OpenAI 안내대로 Codex CLI 를 설치하고 로그인합니다. 확인:

```powershell
codex --version
```

## 등록

```powershell title="터미널"
codex mcp add cadxray -- uvx --from git+https://github.com/WaveSimm/cadxray#subdirectory=bridge cadxray
```

또는 설정 파일 `~/.codex/config.toml` (Windows 는 `C:\Users\<이름>\.codex\config.toml`) 에 직접 적습니다.

```toml title="~/.codex/config.toml"
[mcp_servers.cadxray]
command = "uvx"
args = ["--from", "git+https://github.com/WaveSimm/cadxray#subdirectory=bridge", "cadxray"]
```

포트를 바꿨으면 `args` 끝에 `"--port", "9878"` 을 붙입니다. Windows 에서 `uvx` 를 못 찾으면 `command` 에 전체 경로(`(Get-Command uvx).Source` 결과)를 넣습니다.

## 연결 확인

```powershell
codex mcp list
```

`cadxray` 가 나오면 됩니다. FreeCAD 를 켠 상태에서 `codex` 를 열고 첫 대화를 합니다.

```text title="이렇게 말한다"
cadxray 로 FreeCAD 에 연결되는지 확인하고 버전 알려줘.
```

## 규칙 파일 — AGENTS.md

Codex 는 작업 폴더의 `AGENTS.md` 를 읽습니다. cadxray 의 CLAUDE.md 에 있는 작업 순서를 그 이름으로 저장하면 같은 지침을 따릅니다.

```powershell title="터미널"
mkdir C:\cad-work
cd C:\cad-work
curl -o AGENTS.md https://raw.githubusercontent.com/WaveSimm/cadxray/master/CLAUDE.md
codex
```

파일 안의 "Claude" 라는 말은 그대로 두어도 됩니다. 툴 이름과 순서가 중요하지 호칭은 상관없습니다. 앞부분의 개발자용 규칙(마일스톤·커밋·테스트)은 지워도 됩니다.

## 이 툴에서 다른 점

- **스크린샷**: MCP 가 돌려주는 이미지를 Codex 가 대화에 그리는지는 툴 버전에 따라 다릅니다. 안 보이면 FreeCAD 화면을 직접 봅니다. 수치(부피·자유도·안전율)는 글로 오므로 확인에는 지장이 없습니다.
- **승인 방식**: Codex 는 툴 호출마다 승인을 물을 수 있습니다. 모델링 세션에서는 자동 승인 모드로 두는 편이 편합니다. 어차피 파일 저장은 AI 가 시키기 전엔 하지 않습니다.
- 프롬프트 문장은 Claude Code 와 같습니다. [프롬프트 작성법](/cadxray/prompt/01-structure/) 은 공통입니다.

## 확인 표

| | 명령 | 기대 결과 |
|---|---|---|
| 등록 | `codex mcp list` | `cadxray` |
| 연결 | 첫 대화 | FreeCAD 1.1.3, 툴 36개 |
| 규칙 | 작업 폴더 | `AGENTS.md` 있음 |
